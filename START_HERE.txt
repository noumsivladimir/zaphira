⏱️  TEMPS ESTIMÉ: 5 MINUTES

Bienvenue ! Vous avez une suite de tests complète et prête à utiliser.
Voici comment démarrer en 5 minutes.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 ÉTAPE 1: VÉRIFIER LES PRÉREQUIS (2 minutes)

Ouvrez un terminal et exécutez:

    $ java -version
    $ mvn -v

✅ Vous devez voir:
   - Java version 17 ou plus
   - Maven version 3.8 ou plus

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📦 ÉTAPE 2: PRÉPARER LE PROJET (1 minute)

Assurez-vous que la structure existe:

    ✅ user-service/src/test/resources/application-test-sync.properties
    ✅ wallet-service/src/test/resources/application-test-sync.properties
    
Les fichiers doivent déjà être là. Si ce n'est pas le cas,
consultez FINAL_CHECKLIST.md

🧪 ÉTAPE 3: LANCER LES TESTS (2 minutes)

Exécutez simplement:

    $ make test

OU si Makefile n'est pas disponible:

    $ mvn clean test -Dspring.profiles.active=test-sync

OU sur Windows:

    > run-tests.bat all

💡 POINTS CLÉS À COMPRENDRE:

1️⃣  SQLite (H2) remplace PostgreSQL pour les tests
    → BD en mémoire = rapide et isolée

2️⃣  Feign remplace Kafka pour la communication
    → Communication REST synchrone (plus simple)

3️⃣  Tests isolés sur une seule machine
    → Aucune infrastructure externe
    → Reproductibilité garantie

4️⃣  Configuration par profil Spring
    → @ActiveProfiles("test-sync") active les tests
