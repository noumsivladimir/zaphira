🚀 COMMANDES RAPIDES
═══════════════════════════════════════════════════════════════════════════

Linux/Mac:
  make test                    # Tous les tests
  make test-user               # User-service seulement
  make test-wallet             # Wallet-service seulement
  make test-debug              # Mode debug
  make test-coverage           # Avec couverture de code
  ./run-tests.sh all           # Script alternatif

Windows:
  run-tests.bat all           # Tous les tests
  run-tests.bat user-service  # User-service seulement
  run-tests.bat wallet-service # Wallet-service seulement

Maven Direct:
  mvn clean test -Dspring.profiles.active=test-sync
  mvn test -f user-service/pom.xml -Dspring.profiles.active=test-sync
